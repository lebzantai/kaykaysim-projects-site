# KayKaysim Projects (Pty) Ltd — Demo Website

A static demo website concept for KayKaysim Projects (Pty) Ltd, a civil and
building construction contractor based in the Free State, South Africa.

This is a design/layout demo. Company details, contact information and
project listings are illustrative placeholders unless a page or section
explicitly labels them as sourced/verified.

Source of truth for this content is
[lebzantai/KayKaysim-Projects-Pty-Ltd](https://github.com/lebzantai/KayKaysim-Projects-Pty-Ltd)
(private) — this repo exists only to publish the site via GitHub Pages.

## Pages

- `index.html` — Home
- `about.html` — About Us
- `services.html` — Services
- `projects.html` — Projects
- `contact.html` — Contact

## Deployment

Deploys automatically to GitHub Pages on every push to `main` via
`.github/workflows/deploy-pages.yml`.
